# 聂俊文游戏策划作品集

深圳大学在读硕士，求职方向为游戏策划。本作品集展示个人游戏制作、玩法规则设计、关卡设计、系统拆解与体验优化能力。

**快速入口：[回声协议策划案](回声协议-游戏策划案.pdf) · [系统拆解报告](洛克王国世界S1异色捕捉-系统拆解报告.pdf) · [下载 Windows Demo](https://github.com/JovenLK/game-design-portfolio/releases/latest) · [试玩说明](试玩说明.md)**

## 作品一 回声协议

单人策略解谜游戏，使用 Unity 制作。独立完成游戏 Demo 与配套策划案。

玩家记录行动，生成能够重演路线的回声，利用不同回声同时占用机关完成协作，再由玩家本人抵达出口。围绕这一机制设计 20 关，逐步引入传送、移动障碍、巡逻与追踪敌人，以及后期脉冲工具。

策划案覆盖核心循环、玩法规则、关卡递进、UI 交互、章节剧情、关卡配置与验证要求；Demo 包含首页、关卡地图、教学、暂停、解锁与重玩流程。

## 作品二 洛克王国世界 S1 异色捕捉系统拆解

围绕 S1「暗夜拾光」的异色捕捉系统，拆解刷新供给、捕捉、路线累计、奇遇与稀有获取、收藏、资源补给和结算反馈之间的关系。

报告区分定向追逐与广泛收集的玩家目标，分析奇遇保底与实际投入成本的计数边界，并提出路线与进度可视化方案，补充状态变化、交互反馈、验收条件和体验验证指标。

报告以注明的 S1 研究窗口为依据，优化提案尚未实施，所列指标为验证方案。
