# 回声协议

**记录过去的行动，让回声托住现在的道路。**

《回声协议》是一个使用 Unity 制作的单人策略解谜游戏。玩家记录行动生成回声，让不同回声分别守住机关，再由当前的自己穿越开放的路径、抵达出口。项目围绕这一核心机制设计 20 关，逐步加入传送、动态障碍、巡逻与追踪敌人，以及后期脉冲工具。

作者：JovenL｜个人项目｜求职方向：游戏策划
